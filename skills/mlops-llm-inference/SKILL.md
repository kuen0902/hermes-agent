Outlines (Structured Generation)\n- **Purpose**: JSON Schema, Regex, and Pydantic-base structured output.\n- **Efficiency**: Uses FSM-based guiding for zero-latency structured generation.\n- **Usage**: Preferred over raw parsing for critical data extraction.\n\n## 2. Serving Backends (vLLM, llama.cpp)\n- **vLLM**: High-throughput serving via PagedAttention. Best for datacenter GPUs.\n- **llama.cpp**: GGUF inference for edge/local deployments.\n\n## Common Pitfalls\n- **Tokenization Errors**: Ensure the Outlines tokenizer matches the serving backend's tokenizer to prevent malformed structured output.\n
