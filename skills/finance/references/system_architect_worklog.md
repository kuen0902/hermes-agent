# System Architect Daily Worklog Protocol\n\nThis protocol defines the structure and execution parameters for the daily 08:00 AM status report.\n\n## 1. Core Structure\n\nThe log must contain exactly four sections:\n1. **昨日回顧 (Past Review)**: Major tasks completed in the previous session with timestamps.\n2. **今日重點 (Today's Focus)**: Planned monitoring and maintenance tasks (Intraday monitor, Night updates).\n3. **明日展望 (Future Outlook)**: Upcoming major plans (Data backfilling, new feature pilots).\n4. **系統健康度 (System Health)**: Status check of scripts, cron jobs, and databases.\n\n## 2. Trigger & Fallbacks\n- **Schedule**: Every weekday at 08:00 AM.\n- **Primary Engine**: LLM via `cronjob` (Prompt-driven).\n- **Failure Modes**:\n  - **HTTP 429 (Rate Limit)**: If Ollama or the primary provider hits a limit, the agent must fallback to manual synthesis using `session_search` and `jobs.json` analysis.\n  - **Database Corruption**: If `cronjob` tool fails, manually read `~/.hermes/cron/jobs.json` to extract the prompt instructions.\n\n## 3. Style & Delivery\n- **Tone**: Professional, precise Traditional Chinese.\n- **Format**: Markdown with emoji headers.\n- **Target**: Delivered to `HERMES_GOLD_EXPERIENCE_CHAT_ID` (Telegram Bot Star Platinum).\n
