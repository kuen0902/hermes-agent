# Creative Coding & Animation

This umbrella skill captures methodologies for writing code that generates art, motion graphics, and interactive experiences.

## 1. Mathematical Animation (Manim)
- Create 3Blue1Brown-style explainer videos and algorithmic visualizations using the Manim Community Edition (CE).

## 2. Web Visuals & Shaders (p5.js)
- High-performance 2D/3D generative art, GLSL shaders, and interactive sketches using the p5.js library.

## 3. Real-time Node-based Visuals (TouchDesigner)
- Orchestrate TouchDesigner instances via MCP to manipulate operators, parameters, and wiring for live performance or installation.
