# Social Media Operations

This umbrella skill captures patterns for posting, monitoring, and managing accounts on various social platforms.

## 1. X/Twitter (via xurl)
- **Posting**: High-level command for 280-char posts, threads, and media uploads.
- **Monitoring**: Search and DM handling.
- See `references/xurl.md`.

## 2. Yuanbao (Traditional Social/Groups)
- **Group Management**: Querying info and members in Yuanbao groups.
- See `references/yuanbao.md`.
