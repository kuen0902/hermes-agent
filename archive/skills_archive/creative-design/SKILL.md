# Creative Design & Visualization

This umbrella skill captures patterns for visual communication—from high-level architecture diagrams to low-fidelity ASCII art and rapid mockups.

## 1. Diagramming & Architecture
- **Infrasctructure**: Create dark-themed SVG architecture diagrams as HTML.
- **Hand-drawn**: Use **Excalidraw** (JSON-based) for flowcharts and sequence diagrams.
- **Token Spec**: Validate and export Google DESIGN.md token files.

## 2. Low-Fidelity & Text Art
- **ASCII Art**: Generate banners and image-to-ascii conversion (pyfiglet, cowsay).
- **Typographic Layout**: Use the **Pretext** DOM-free text layout engine for creative browser demos.

## 3. Rapid Prototyping
- **Mockups**: Generate throwaway HTML variants to compare design directions.
- **Design Systems**: Leverage patterns from real design systems (Stripe, Linear, Vercel) as reference.
