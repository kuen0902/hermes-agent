# Hermes Maintenance Scripts

This directory contains scripts for system health and troubleshooting.

## Scripts

- **cleanup_hermes.py**: Automates the organization of the `.hermes` directory.
- **fix_venv.py**: Repairs virtual environment paths after moving the workspace.
- **fix_workspace.py**: Resolves path inconsistencies and restores database files.
- **kill_hermes.sh**: Forcefully stops all Hermes-related processes.

> [!NOTE]
> Run these scripts only when troubleshooting or performing system updates.
